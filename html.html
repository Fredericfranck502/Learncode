1. Introduction au HTML

HTML signifie HyperText Markup Language. C'est un langage de balisage qui permet de structurer le contenu d'une page web.

Avec HTML, on peut ajouter :

  • Des titres et des paragraphes.
  • Des images.
  • Des liens.
  • Des tableaux.
  • Des formulaires.
À retenir : HTML construit la structure, CSS s'occupe de la présentation et JavaScript ajoute des interactions.

Exemple simple

<h1>Bienvenue sur mon site</h1>
<p>J'apprends le HTML.</p>

Exercice

Crée un titre contenant ton prénom et un paragraphe qui présente ton site.

2. Structure d'une page HTML

Chaque document HTML possède une structure de base. Elle permet au navigateur de comprendre le contenu de la page. 

<!DOCTYPE html>
<html lang="fr">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <title>Ma première page</title>
</head>

<body>

    <h1>Bienvenue</h1>
    <p>Ma première page web.</p>

</body>
</html>

Explication

  • DOCTYPE : indique HTML5.
  • html : contient toute la page.
  • head : contient les informations de la page.
  • title : définit le titre de l'onglet.
  • body : contient le contenu visible.
Attention : la plupart des éléments HTML s'écrivent avec une balise ouvrante et une balise fermante.

Exercice

Crée un fichier nommé index.html et reproduis la structure ci-dessus.

3. Les titres et les paragraphes

HTML propose six niveaux de titres : de h1 à h6. 

<h1>Grand titre</h1>
<h2>Titre secondaire</h2>
<h3>Petit titre</h3>

<p>Ceci est un paragraphe.</p>

<strong>Texte important</strong>

<em>Texte mis en valeur</em>

<br>

<hr>

À quoi servent ces balises ?

  • h1 à h6 : les titres.
  • p : les paragraphes.
  • strong : le texte important.
  • em : le texte mis en valeur.
  • br : un retour à la ligne.
  • hr : une séparation horizontale.

Exercice

Crée une page avec un grand titre, deux sous-titres et trois paragraphes.

4. Les liens HTML

La balise a permet de créer un lien vers une autre page ou un site web. 

<a href="https://www.google.com">
    Visiter Google
</a>

Ouvrir un lien dans un nouvel onglet

<a href="https://www.google.com"
target="_blank"
rel="noopener noreferrer">
    Ouvrir Google
</a>

Lien vers une autre page de ton site

<a href="contact.html">
    Contact
</a>

Exercice

Crée trois liens : Accueil, À propos et Contact. Chaque lien doit ouvrir une page différente.

5. Insérer des images

La balise img permet d'afficher une image sur une page web. 

<img src="images/photo.jpg"
alt="Photo de présentation">

Les attributs importants

  • src : chemin vers l'image.
  • alt : description de l'image.
  • width : largeur.
  • height : hauteur.

Exemple

<img src="images/logo.png"
alt="Logo LearnCode"
width="200">
Conseil : place tes images dans un dossier nommé images pour mieux organiser ton projet.

Exercice

Ajoute une image à ta page HTML et donne-lui une description avec l'attribut alt.

6. Les listes HTML

Il existe deux types de listes principales.

Liste non ordonnée

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Liste ordonnée

<ol>
    <li>Créer un fichier HTML</li>
    <li>Ajouter le contenu</li>
    <li>Ajouter le CSS</li>
</ol>

Différence

  • ul : liste avec des puces.
  • ol : liste numérotée.
  • li : élément de la liste.

Exercice

Présente cinq matières que tu souhaites apprendre avec une liste ordonnée.

7. Les tableaux HTML

Les tableaux permettent d'organiser des informations en lignes et en colonnes. 

<table>

    <tr>
        <th>Nom</th>
        <th>Âge</th>
    </tr>

    <tr>
        <td>Franck</td>
        <td>20</td>
    </tr>

</table>

Les balises

  • table : crée le tableau.
  • tr : crée une ligne.
  • th : crée une cellule de titre.
  • td : crée une cellule normale.

Exercice

Crée un tableau contenant trois étudiants avec leurs noms et leurs notes.

8. Les formulaires HTML

Un formulaire permet à un utilisateur de saisir et d'envoyer des informations. 

<form action="#" method="post">

    <label for="nom">Votre nom</label>
    <input type="text" id="nom"
    name="nom" required>

    <label for="email">Votre email</label>
    <input type="email" id="email"
    name="email" required>

    <label for="message">Message</label>
    <textarea id="message"
    name="message"></textarea>

    <button type="submit">
        Envoyer
    </button>

</form>

Les principaux champs

  • text : texte simple.
  • email : adresse email.
  • password : mot de passe.
  • number : nombre.
  • date : date.
  • textarea : texte long.
  • button : bouton.
Un formulaire HTML seul ne stocke pas les informations. Pour recevoir et enregistrer les données, il faut un traitement côté serveur ou un service adapté.

Exercice

Crée un formulaire d'inscription avec : nom, email, mot de passe et bouton Envoyer.

9. Les attributs HTML

Les attributs ajoutent des informations supplémentaires aux balises HTML. 

<input type="text"
placeholder="Votre nom"
required>

<a href="contact.html"
title="Page de contact">
    Contact
</a>

<img src="photo.jpg"
alt="Une photo">

Quelques attributs courants

  • id : identifiant unique.
  • class : classe pour CSS.
  • href : destination d'un lien.
  • src : source d'une image.
  • title : information complémentaire.
  • required : champ obligatoire.
  • placeholder : texte indicatif.

Exercice

Crée un champ email avec un placeholder et l'attribut required.

10. Le HTML sémantique

Les balises sémantiques donnent un sens précis aux différentes parties d'une page. 

<header>
    En-tête du site
</header>

<nav>
    Navigation
</nav>

<main>
    <section>
        Une section
    </section>

    <article>
        Un article
    </article>
</main>

<footer>
    Pied de page
</footer>

Les balises principales

  • header : en-tête.
  • nav : menu de navigation.
  • main : contenu principal.
  • section : section de contenu.
  • article : contenu autonome.
  • footer : pied de page.
  • aside : contenu complémentaire.

Exercice

Construis une page contenant un header, un menu, un main et un footer.

11. Ajouter des vidéos et de l'audio

Insérer une vidéo

<video controls width="400">
    <source src="video.mp4"
    type="video/mp4">

    Votre navigateur ne supporte pas la vidéo.
</video>

Insérer un fichier audio

<audio controls>
    <source src="musique.mp3"
    type="audio/mpeg">

    Votre navigateur ne supporte pas l'audio.
</audio>

L'attribut controls affiche les commandes de lecture.

Exercice

Ajoute une vidéo locale à une page HTML avec les commandes de lecture.

12. Projet pratique : créer une page personnelle

Pour terminer cette formation HTML, tu vas créer une petite page personnelle.

Objectif

  • Créer un titre principal.
  • Ajouter une présentation.
  • Insérer une photo.
  • Créer une liste de compétences.
  • Ajouter un lien de contact.
  • Créer un formulaire simple.

Code de départ

<!DOCTYPE html>
<html lang="fr">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <title>Ma présentation</title>
</head>

<body>

    <header>
        <h1>Bienvenue sur mon site</h1>
    </header>

    <main>
        <section>
            <h2>À propos de moi</h2>
            <p>Je suis en formation informatique.</p>
        </section>

        <section>
            <h2>Mes compétences</h2>
            <ul>
                <li>HTML</li>
                <li>CSS</li>
            </ul>
        </section>
    </main>

    <footer>
        <p>Mon premier projet HTML</p>
    </footer>

</body>
</html>
Défi final : Termine cette page sans copier les exemples. Essaie de construire chaque partie toi-même.
