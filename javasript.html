1. Introduction à JavaScript

JavaScript est un langage de programmation utilisé pour rendre les pages web interactives.

Il permet par exemple de :

  • Afficher des messages.
  • Réagir aux clics sur les boutons.
  • Vérifier les formulaires.
  • Modifier le contenu HTML.
  • Créer des applications web.

Ajouter JavaScript dans HTML

<script>
    alert("Bienvenue sur LearnCode !");
</script>

Utiliser un fichier externe

<script src="script.js" defer></script>

Le mot defer permet au navigateur de charger le script sans bloquer l'analyse HTML.

HTML structure la page, CSS la met en forme et JavaScript ajoute des comportements.

Exercice

Crée un fichier script.js et affiche un message dans la console avec console.log().

2. Les variables

Une variable permet de stocker une information que le programme pourra utiliser.

Avec let

let nom = "Franck";
let age = 20;

console.log(nom);
console.log(age);

Avec const

const pays = "Madagascar";

console.log(pays);

Différence

  • let : valeur réassignable.
  • const : variable non réassignable.
  • var : ancienne manière de déclarer une variable.

Exercice

Crée trois variables : prénom, ville et formation. Affiche-les avec console.log().

3. Les types de données

JavaScript possède plusieurs types de données. 

let nom = "Franck";       // String
let age = 20;             // Number
let actif = true;         // Boolean
let resultat;             // Undefined
let valeur = null;        // Null

Les principaux types

  • String : texte.
  • Number : nombre.
  • Boolean : vrai ou faux.
  • Undefined : valeur non définie.
  • Null : absence volontaire de valeur.
  • Object : objet.
  • Array : tableau.

Vérifier le type

let age = 20;

console.log(typeof age);

4. Les opérateurs

Les opérateurs permettent de réaliser des calculs et des comparaisons.

Opérateurs arithmétiques

let a = 10;
let b = 3;

console.log(a + b); // Addition
console.log(a - b); // Soustraction
console.log(a * b); // Multiplication
console.log(a / b); // Division
console.log(a % b); // Reste
console.log(a ** b); // Puissance

Opérateurs de comparaison

console.log(10 > 5);
console.log(10 < 5);
console.log(10 === 10);
console.log(10 !== 5);
console.log(10 >= 10);

Opérateurs logiques

let age = 20;

console.log(age >= 18 && age <= 30);
console.log(age < 18 || age > 60);
console.log(!(age < 18));
  • && : ET.
  • || : OU.
  • ! : NON.

5. Les conditions

Les conditions permettent d'exécuter des instructions selon une situation.

Condition if

let age = 20;

if (age >= 18) {
    console.log("Majeur");
}

if et else

let note = 12;

if (note >= 10) {
    console.log("Admis");
} else {
    console.log("Non admis");
}

if, else if et else

let note = 15;

if (note >= 16) {
    console.log("Très bien");
} else if (note >= 14) {
    console.log("Bien");
} else if (note >= 10) {
    console.log("Passable");
} else {
    console.log("Insuffisant");
}

Switch

let jour = 2;

switch (jour) {
    case 1:
        console.log("Lundi");
        break;

    case 2:
        console.log("Mardi");
        break;

    default:
        console.log("Autre jour");
}

6. Les boucles

Les boucles permettent de répéter des instructions plusieurs fois.

Boucle for

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Boucle while

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Boucle do...while

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Break et continue

for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);
}

break arrête la boucle. continue passe directement à l'itération suivante.

7. Les fonctions

Une fonction est un bloc de code réutilisable. Elle peut recevoir des paramètres et retourner un résultat.

Créer une fonction

function saluer() {
    console.log("Bonjour !");
}

saluer();

Fonction avec paramètre

function saluer(nom) {
    console.log("Bonjour " + nom);
}

saluer("Franck");

Fonction avec return

function addition(a, b) {
    return a + b;
}

let resultat = addition(5, 3);

console.log(resultat);

Fonction fléchée

const carre = (nombre) => {
    return nombre * nombre;
};

console.log(carre(4));
À retenir : console.log() affiche une information. return renvoie une valeur que le programme peut réutiliser.

8. Les tableaux

Un tableau permet de stocker plusieurs valeurs dans une seule variable.

Créer un tableau

let langages = [
    "HTML",
    "CSS",
    "JavaScript"
];

Accéder aux éléments

console.log(langages[0]);
console.log(langages[1]);
console.log(langages[2]);

Attention : le premier indice d'un tableau est 0.

Ajouter un élément

langages.push("Python");

Supprimer le dernier élément

langages.pop();

Parcourir un tableau

for (let i = 0; i < langages.length; i++) {
    console.log(langages[i]);
}

Utiliser for...of

for (let langage of langages) {
    console.log(langage);
}

9. Les objets

Un objet permet de regrouper plusieurs informations sous forme de propriétés et de valeurs.

Créer un objet

let etudiant = {
    nom: "Franck",
    age: 20,
    ville: "Toliara"
};

Accéder aux propriétés

console.log(etudiant.nom);
console.log(etudiant.age);

console.log(etudiant["ville"]);

Modifier une propriété

etudiant.age = 21;

Ajouter une propriété

etudiant.formation = "Développement web";

10. Le DOM

DOM signifie Document Object Model. Il permet à JavaScript d'accéder aux éléments HTML et de les modifier.

Sélectionner un élément

document.getElementById("titre");

document.querySelector(".carte");

document.querySelectorAll("p");

Modifier le texte

let titre = document.getElementById("titre");

titre.textContent = "Nouveau titre";

Modifier le style

let titre = document.getElementById("titre");

titre.style.color = "blue";
titre.style.fontSize = "30px";

Modifier une classe

let boite = document.querySelector(".boite");

boite.classList.add("active");
boite.classList.remove("active");
boite.classList.toggle("active");

11. Les événements

Les événements permettent de réagir aux actions de l'utilisateur : clic, saisie, survol, etc.

Événement click

HTML :

<button id="bouton">Clique ici</button>

JavaScript :

let bouton = document.getElementById("bouton");

bouton.addEventListener("click", function() {
    alert("Tu as cliqué !");
});

Événement input

<input type="text" id="nom">
<p id="resultat"></p>
let champ = document.getElementById("nom");
let resultat = document.getElementById("resultat");

champ.addEventListener("input", function() {
    resultat.textContent = champ.value;
});

Quelques événements

  • click : clic.
  • input : saisie.
  • change : changement de valeur.
  • submit : envoi de formulaire.
  • mouseover : passage du pointeur.
  • keydown : touche pressée.

12. Projet pratique : compteur interactif

Pour terminer, crée un compteur qui augmente ou diminue lorsqu'on clique sur les boutons.

HTML

<h2 id="compteur">0</h2>

<button id="diminuer">-</button>
<button id="augmenter">+</button>

<script src="script.js" defer></script>

JavaScript

let nombre = 0;

const compteur = document.getElementById("compteur");
const augmenter = document.getElementById("augmenter");
const diminuer = document.getElementById("diminuer");

augmenter.addEventListener("click", function() {
    nombre++;
    compteur.textContent = nombre;
});

diminuer.addEventListener("click", function() {
    nombre--;
    compteur.textContent = nombre;
});

Défis supplémentaires

  1. Ajoute un bouton pour remettre le compteur à zéro.
  2. Empêche le compteur de devenir négatif.
  3. Change la couleur du nombre selon sa valeur.
Défi final : Réalise le compteur sans regarder la correction, puis teste-le dans ton navigateur.
