1. Introduction au CSS

CSS signifie Cascading Style Sheets. Il permet de modifier l'apparence des pages HTML : couleurs, tailles, espacements, disposition et animations.

Comment ajouter du CSS ?

Il existe trois méthodes principales.

CSS en ligne

<p style="color: red;">
    Bonjour !
</p>

CSS interne

<style>
    p {
        color: blue;
    }
</style>

CSS externe

<link rel="stylesheet" href="style.css">
La méthode externe est recommandée pour organiser un vrai projet web.

Exercice

Relie un fichier HTML à un fichier style.css.

2. Les sélecteurs CSS

Un sélecteur permet de choisir les éléments HTML auxquels on veut appliquer un style.

Sélecteur de balise

p {
    color: blue;
}

Sélecteur de classe

.titre {
    color: green;
}

Dans HTML :

<h1 class="titre">Bienvenue</h1>

Sélecteur d'identifiant

#principal {
    background: lightgray;
}

Dans HTML :

<section id="principal">
    Contenu principal
</section>

Sélecteur universel

* {
    margin: 0;
    padding: 0;
}

Exercice

Applique une couleur rouge à tous les paragraphes, une couleur verte à une classe .titre et un fond gris à un élément ayant l'id #principal.

3. Les couleurs et les arrière-plans

CSS permet de définir les couleurs du texte, les arrière-plans et les bordures. 

body {
    background-color: #f2f2f2;
}

h1 {
    color: blue;
}

p {
    color: rgb(50, 50, 50);
}

Différentes écritures

color: red;

color: #ff0000;

color: rgb(255, 0, 0);

color: rgba(255, 0, 0, 0.5);

Image en arrière-plan

.hero {
    background-image: url("images/fond.jpg");
    background-size: cover;
    background-position: center;
}

Exercice

Crée une page avec un fond clair, un titre bleu et un paragraphe gris.

4. La typographie

La typographie concerne l'apparence des textes : police, taille, épaisseur et alignement. 

h1 {
    font-family: Arial, sans-serif;
    font-size: 32px;
    font-weight: bold;
    text-align: center;
}

p {
    font-size: 16px;
    line-height: 1.6;
    text-align: justify;
}

Propriétés importantes

  • font-family : police.
  • font-size : taille.
  • font-weight : épaisseur.
  • text-align : alignement.
  • line-height : hauteur de ligne.
  • text-decoration : décoration du texte.

Exercice

Crée un titre centré de 36px et un paragraphe de 18px avec une hauteur de ligne de 1.5.

5. Les espacements : margin et padding

Ces propriétés permettent de gérer les espaces autour et à l'intérieur des éléments.

Margin

.carte {
    margin: 20px;
}

margin crée un espace extérieur autour de l'élément.

Padding

.carte {
    padding: 20px;
}

padding crée un espace intérieur entre le contenu et la bordure.

Définir chaque côté

.carte {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;
}

Exercice

Crée une carte avec 20px de padding et 15px de margin.

6. Le Box Model

Chaque élément HTML est représenté comme une boîte. Cette boîte contient quatre parties :

  • Content : contenu.
  • Padding : espace intérieur.
  • Border : bordure.
  • Margin : espace extérieur.
* {
    box-sizing: border-box;
}

.card {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
    margin: 15px;
}
À retenir : box-sizing: border-box; permet d'inclure le padding et la bordure dans la largeur définie.

Exercice

Crée une boîte de 300px de largeur avec une bordure de 2px et un padding de 20px.

7. La propriété Display

La propriété display définit la manière dont un élément apparaît et occupe l'espace.

Display block

div {
    display: block;
}

Un élément block commence généralement sur une nouvelle ligne et occupe toute la largeur disponible.

Display inline

span {
    display: inline;
}

Un élément inline reste dans la ligne du texte.

Display inline-block

.bouton {
    display: inline-block;
    width: 150px;
    padding: 10px;
}

Display none

.cache {
    display: none;
}

L'élément n'est plus affiché et ne réserve plus son espace habituel.

Exercice

Crée trois éléments et teste block, inline et inline-block pour observer les différences.

8. Flexbox

Flexbox permet d'organiser facilement des éléments sur une ligne ou une colonne.

Activer Flexbox

.container {
    display: flex;
}

Direction

.container {
    display: flex;
    flex-direction: row;
}
  • row : éléments sur une ligne.
  • column : éléments en colonne.
  • row-reverse : ligne inversée.
  • column-reverse : colonne inversée.

Justify-content

.container {
    display: flex;
    justify-content: center;
}

Cette propriété organise les éléments sur l'axe principal.

  • flex-start
  • center
  • flex-end
  • space-between
  • space-around
  • space-evenly

Align-items

.container {
    display: flex;
    align-items: center;
}

Cette propriété aligne les éléments sur l'axe transversal.

Gap

.container {
    display: flex;
    gap: 20px;
}

Exemple complet

.container {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}

.box {
    width: 100px;
    padding: 20px;
    background: lightblue;
}

HTML correspondant :

<div class="container">
    <div class="box">1</div>
    <div class="box">2</div>
    <div class="box">3</div>
</div>
Flexbox est particulièrement utile pour les menus, les boutons, les cartes et les alignements.

Exercices

  1. Aligne trois boîtes horizontalement.
  2. Centre-les avec justify-content.
  3. Place-les en colonne.
  4. Ajoute un espace de 15px avec gap.
  5. Centre-les verticalement dans un conteneur.

9. CSS Grid

Grid permet de créer des mises en page organisées en lignes et en colonnes.

Activer Grid

.container {
    display: grid;
}

Créer trois colonnes

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 20px;
}

Utiliser repeat()

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Créer deux lignes

.container {
    display: grid;
    grid-template-rows: 100px 200px;
}

Grid responsive

.container {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}
Flexbox est souvent utilisé pour organiser les éléments dans une direction. Grid est particulièrement pratique pour les mises en page en deux dimensions.

Exercices

  1. Crée une grille de trois colonnes.
  2. Ajoute six cartes.
  3. Ajoute un espace de 20px.
  4. Rends la grille adaptable aux petits écrans.

10. Le positionnement

La propriété position permet de contrôler la position d'un élément.

Static

.box {
    position: static;
}

C'est le positionnement normal par défaut.

Relative

.box {
    position: relative;
    top: 10px;
    left: 20px;
}

L'élément est déplacé par rapport à sa position normale.

Absolute

.parent {
    position: relative;
}

.enfant {
    position: absolute;
    top: 10px;
    right: 10px;
}

L'élément absolute se positionne par rapport à son ancêtre positionné le plus proche.

Fixed

.menu {
    position: fixed;
    top: 0;
    left: 0;
}

L'élément reste fixé par rapport à la fenêtre du navigateur.

Sticky

.menu {
    position: sticky;
    top: 0;
}

L'élément suit le défilement puis reste collé à la position définie.

Exercice

Crée un menu avec position: fixed puis teste son comportement lorsque tu fais défiler la page.

11. Les pseudo-classes

Les pseudo-classes permettent de styliser un élément selon son état.

Hover

button:hover {
    background: blue;
    color: white;
}

Le style s'applique lorsque le pointeur passe dessus.

Active

button:active {
    transform: scale(0.95);
}

Le style s'applique pendant l'activation du bouton.

Visited

a:visited {
    color: purple;
}

Le style s'applique aux liens déjà visités.

Focus

input:focus {
    border: 2px solid blue;
    outline: none;
}

Le style s'applique quand le champ reçoit le focus.

First-child

li:first-child {
    color: red;
}

Last-child

li:last-child {
    color: green;
}

Exercice

  1. Crée un bouton avec hover.
  2. Ajoute un effet active.
  3. Change la couleur des liens visités.
  4. Modifie la bordure d'un input au focus.

12. Les transitions et animations

Transition

.bouton {
    background: blue;
    transition: 0.3s ease;
}

.bouton:hover {
    background: green;
}

Transition permet de rendre un changement de style progressif.

Animation avec @keyframes

@keyframes mouvement {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(100px);
    }
}

.boite {
    animation: mouvement 2s infinite alternate;
}

Exercice

Crée un bouton qui change progressivement de couleur lorsque tu passes dessus.

13. Le Responsive Design

Le responsive design permet à un site web de s'adapter aux écrans des téléphones, tablettes et ordinateurs.

La règle media query

.container {
    display: flex;
    gap: 20px;
}

@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

Plusieurs tailles d'écran

@media (max-width: 900px) {
    .container {
        gap: 15px;
    }
}

@media (max-width: 600px) {
    h1 {
        font-size: 25px;
    }

    .container {
        flex-direction: column;
    }
}
La balise viewport dans le HTML est importante pour que les media queries fonctionnent comme prévu sur les téléphones.

Exercice

Crée trois cartes alignées sur ordinateur, puis empilées verticalement sur téléphone.

14. Créer une Navbar professionnelle

Une navbar est un menu de navigation qui permet de passer d'une page à une autre.

HTML

<header class="header">

    <a href="#" class="logo">MonSite</a>

    <nav class="navbar">
        <a href="index.html">Accueil</a>
        <a href="about.html">À propos</a>
        <a href="services.html">Services</a>
        <a href="contact.html">Contact</a>
    </nav>

</header>

CSS

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

.header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 20px 40px;
    background: #22243a;
}

.logo {
    color: white;
