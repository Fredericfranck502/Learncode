ENTRAÎNEMENT PRATIQUE

Exercices de programmation

Entraînez-vous avec des exercices progressifs pour améliorer vos compétences en développement web.

Comment utiliser cette page ?

Lisez chaque exercice, essayez de le résoudre vous-même, puis ouvrez la correction pour comparer votre réponse.

Conseil : essayez toujours de résoudre l'exercice avant de regarder la correction.

Partie 1 : Exercices HTML

Objectif : apprendre à structurer une page web.

Exercice HTML 1 : Premier titre

Crée une page HTML contenant un titre principal qui affiche « Bienvenue sur LearnCode ».

Voir la correction 
<h1>Bienvenue sur LearnCode</h1>

Exercice HTML 2 : Présentation

Crée un titre « À propos de moi » et un paragraphe qui présente brièvement un étudiant.

Voir la correction 
<h2>À propos de moi</h2>
<p>Je suis étudiant et j'apprends
le développement web.</p>

Exercice HTML 3 : Liste

Crée une liste contenant HTML, CSS et JavaScript.

Voir la correction 
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Exercice HTML 4 : Lien

Crée un lien qui permet de visiter le site officiel de Google.

Voir la correction 
<a href="https://www.google.com">
    Visiter Google
</a>

Exercice HTML 5 : Formulaire

Crée un formulaire contenant un champ nom, un champ email et un bouton Envoyer.

Voir la correction 
<form>
    <label for="nom">Nom</label>
    <input type="text" id="nom"
    name="nom" required>

    <label for="email">Email</label>
    <input type="email" id="email"
    name="email" required>

    <button type="submit">
        Envoyer
    </button>
</form>

Partie 2 : Exercices CSS

Objectif : apprendre à styliser les pages web.

Exercice CSS 1 : Couleur du texte

Mets tous les titres h1 en bleu.

Voir la correction 
h1 {
    color: blue;
}

Exercice CSS 2 : Hover

Crée un bouton qui devient vert lorsque le pointeur passe dessus.

Voir la correction 
button {
    background: blue;
    color: white;
}

button:hover {
    background: green;
}

Exercice CSS 3 : Flexbox

Aligne trois cartes horizontalement avec un espace de 20px.

Voir la correction 
.container {
    display: flex;
    gap: 20px;
}

Exercice CSS 4 : Grid

Crée une grille de trois colonnes de même largeur.

Voir la correction 
.container {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
    gap: 20px;
}

Exercice CSS 5 : Responsive

Sur un écran de 600px ou moins, affiche les cartes verticalement.

Voir la correction 
@media (max-width: 600px) {
    .container {
        display: flex;
        flex-direction: column;
    }
}

Partie 3 : Exercices JavaScript

Objectif : apprendre les bases de la programmation.

Exercice JavaScript 1 : Variables

Crée une variable nom contenant ton prénom et affiche-la dans la console.

Voir la correction 
let nom = "Franck";

console.log(nom);

Exercice JavaScript 2 : Addition

Crée deux variables a et b puis affiche leur somme.

Voir la correction 
let a = 10;
let b = 5;

let somme = a + b;

console.log(somme);

Exercice JavaScript 3 : Condition

Vérifie si un nombre est positif ou négatif.

Voir la correction 
let nombre = -5;

if (nombre > 0) {
    console.log("Positif");
} else if (nombre < 0) {
    console.log("Négatif");
} else {
    console.log("Zéro");
}

Exercice JavaScript 4 : Boucle

Affiche les nombres de 1 à 10 avec une boucle for.

Voir la correction 
for (let i = 1; i <= 10; i++) {
    console.log(i);
}

Exercice JavaScript 5 : Fonction

Crée une fonction qui reçoit deux nombres et retourne leur produit.

Voir la correction 
function multiplication(a, b) {
    return a * b;
}

let resultat = multiplication(4, 5);

console.log(resultat);

Bravo pour ton entraînement !

Continue à pratiquer régulièrement. La programmation s'apprend en écrivant, testant et corrigeant du code.
